# P2：x86_64 静态链接器

## 输入

- mt/as 生成的 ET_REL；
- mt/ar 归档及其 symbol index；
- meuos-libc 的 `crt1.o`、`libc-meuos.a`、`libatomic-meuos.a`。

## 交付

- 符号解析和归档按需抽取；
- 节区布局、PT_LOAD、入口点；
- x86_64 首期 relocation；
- `--sysroot/-L/-l/--static/-o`。

## 门禁

- 静态 hello、stdio、atomic、threads 程序；
- x86_64 宿主或 QEMU 运行；
- 未定义符号和 relocation 溢出诊断；
- 不调用宿主 `ld`。
