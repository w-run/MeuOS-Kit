# P1：x86_64 汇编器（核心完成）

## 输入

- mcc x86_64 emitter 输出的 AT&T 汇编；
- MeuOS libc 的 `crt1.S`、原子、TLS、setjmp 等运行时汇编。

## 交付

- `.s -> ELF64 ET_REL .o`；
- mcc 当前实际输出指令和 MeuOS libc x86_64 crt/runtime 汇编的编码；
- 符号、节区、局部/全局标签和首期 relocation；
- 可定位的行列错误。

## 已完成门禁

- `make -C projects/meuos-toolchain check-as-x86_64 check-as-libc-x86_64`；
- `readelf -h/-S/-r/-s` 可读取；
- mcc 生成的 x86_64 整数/数据/调用 fixture 可通过 mt/as 并由宿主 ld 运行；
- 不调用宿主 `as`；
- 已覆盖 C 注释、numeric labels、SIB address、atomic lock/xadd/cmpxchg、mfence/hlt/syscall。

## 后续扩展

- SSE/AVX 浮点、TLS、复杂 SIB、完整 GNU 伪指令和 i386/aarch64 target。
