# P1：x86_64 汇编器

## 输入

- mcc x86_64 emitter 输出的 AT&T 汇编；
- MeuOS libc 的 `crt1.S`、原子、TLS、setjmp 等运行时汇编。

## 交付

- `.s -> ELF64 ET_REL .o`；
- mcc 当前实际输出指令的编码；
- 符号、节区、局部/全局标签和首期 relocation；
- 可定位的行列错误。

## 门禁

- golden instruction bytes；
- `readelf -h/-S/-r/-s` 可读取；
- mcc 生成的 x86_64 汇编全量通过；
- 不调用宿主 `as`。
