### §3.3 bit 48+ 预留区纪律注记

- **bit 48**：维持冻结仅 `SCENE_SESSION` 候选描述（C-G3 防御性说明继续有效）；
- **bit 49–55**：第八轮首冻结——`IO_*`/`UART_*`(49)/`CLOCK_ADJUST`(50)/`CLOCK_MINT`(51)/`IRQ_WAIT`(52)/`IRQ_ACK`(53)/`IRQ_MASK`(54)/`AUTH_ISSUE`(55)；均 deny、Day 1 不触发、不挤占 bit 0–47；与 `38 §3`/`45 §3` 统一 rights bit 分配表纪律一致；
- **bit 56+**：仍归未来——`69 V1` 立场 A 不新增 bit56+ `GUEST_INTR_INJECT`（仅候选预留不分配）；立场 B 触发时由 `07` owner 协同 `59` 定稿；
- **第九轮 6 项裁决 + 6 新维度零新增 bit**：S1 专属 `AUDIT_*` 仅预留不分配、D1 不新增调试专属 right、V1 立场 A 不新增 bit56+；`71`–`76` 全部零新增 right bit；
- **专属 right 不复用 `MANAGE`/`GRANT`**：与 D-T1 同构「领域专属 right、不复用通用 right」先例继续生效。

### §5.3 与既有地基对齐（一句话总览）

> 第九轮查缺补漏与拓展收敛**未引入任何新的内核裁决机制**、**未引入任何新的 right bit**（V1 立场 A 不新增 bit56+，与第八轮首冻结纪律完全自洽）、**未触碰既有 C1–C18 / V1 / R1 / D-T1 / 能耗-Job / C-G1~C-G5 / 第七轮 C61-1~4·C60-1·多 realm / 第八轮 bit 49–55 冻结 / 第八轮 C18 / 第八轮多 realm 边界 等自主采纳项**——所有结论均建立在 `00 §2` A1–A12 地基之上：

- **capability 唯一权限源**（A1 / `07 §2.3`）：12 份新文档全部 Day 1 即由 capability 表达，零回退路径；
- **Day 1 唯一 capability 模型**（A2）：本轮未引入任何「先传统再 capability」回退；`71` 兼容层翻译 Linux 语义而非暴露特权；
- **Rust 管安全关键路径、最小 TCB**（A3）：`71`/`72`/`73`/`74`/`75`/`76` 全部按 `02` 约束入 TCB；i386 纯 C 约束只影响早期引导 C 后端；
- **统一资源命名空间**（A4 / C3）：`72` 容器 = Job + namespace 组合；`73` 快照 Merkle 进 `.msys` 度量基；多 realm 边界（第八轮已采纳）继续生效；
- **Job 资源账本 Day 1**（A5）：`68 Sc5` 监督者默认 restart、`72` 容器 Job、`76` 物理页分配点即配额扣减点；与 `04 §4.4` 完全自洽；
- **重服务出核缩 TCB**（A6 / A11）：`71` 兼容层用户态蹦床 / `72` 容器运行时出核 / `73` 备份导出经用户态 device VMO / `74` perf counter 用户态消费面 / `75` 形式化只证算法本体 / `76` 物理页分配器关键路径 Rust；
- **结构化取消 / 异常上行**（A9 / `04 §4.6`）：`68 Sc5` CPU 硬上限走结构化取消 / `65` 审计事件经 exception channel / `63` netstack 单例崩溃走同一上行 / `69` VMM 崩溃走同一上行；
- **mkit 子集优先 + 内核态薄层**（A10）：`71` syscall 入口经内核态 mkit 薄层翻译为 native capability 调用；
- **`.msys` 为自举/回滚媒介**（A11）：`73` 持久化快照 = `.msys` A/B repoint + C61-4 引导级恢复指针的上层可枚举资源面；`69 V2` 扩展 `.mimg` Item 携带 guest measurement 子项同构；
- **调试即 capability（默认拒绝）**（A12）：`67 D1` 采纳不新增调试专属 right，与 A12 完全自洽；
- **C16 / CFG_***：C18「内核零运行期代码加载」写入 `07` C16 ② 编译期固定安全参数清单；`74` perf counter 复用 `12` 可观测权不新增；
- **C15 / C17 / V1**：网络面边界（C17 已采纳为「网络面边界」）；`63 N13` 单例 netstack 与 C15 同源；`69 V1` 立场 A 与 V1 已采纳同源；
- **D-T1 / `KERNEL_PRIV`**：bit 49–55 均不复用 `MANAGE`/`GRANT`，与 D-T1 同构「领域专属 right、不复用通用 right」先例；
- **能耗-Job**：`74 B4`/`72 C3` 能耗基准严格在弱耦合结论内，**不升格**为 Job 账本硬配额；
- **C-G1 / C-G2 / C-G3 / C-G4 / C-G5**：`73` 与 C-G1 同源；`71`/`74` 与 C-G2 B 主线零冲突；`67 D1`/`69 V1` 与 C-G3 防御性说明同源；`72 C1` 与 C-G4 同源；`73` 与 C-G5 命名空间边界同源。
