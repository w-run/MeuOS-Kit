## 2. 第三轮 6 新维度一句话汇总（25–30）

- **25-网络栈与协议**：完全用户态 netstack3 风格、socket 句柄即 capability、防火墙 capability 门控、`/net` 并入统一命名空间，与 05/06/07/08/10 接口边界对齐。
- **26-虚拟化与隔离**：用户态 VMM + 薄内核 guest 设施 + 设备 VMO 直通（非 KVM 单体内核方案），VM / 容器 / capability 三栈统一于同一隔离模型。
- **27-电源与热管理**：内核态暴露功耗/热原语 + 不可绕过热硬限的机制层，用户态 `powerd` 策略层，调度器据 Job 账本做能耗感知 EAS。
- **28-实时性与确定性**：圈定 RT 域（特定 Job / CPU 子集 / 锁定内存），数据通路留核 + RT 中断留核，确定性可分级、不强行承诺全系统硬实时。
- **29-威胁模型**：以 capability 边界 / TCB / 侧信道 / 拒绝服务为轴梳理攻击面，标定 **D-T1 内核态高危能力**为最高优先裁决项。
- **30-内核可配置性**：编译期 feature（能力集 / TCB / 五架构）与运行期 tunable（capability 守护、有界、可回滚）彻底二分，`CFG_*` rights 并入统一模型。
