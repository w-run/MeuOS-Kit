# Reference Projects

C/C++ compiler frontend reference implementations for mxx development.

| Project | Source | Size | Purpose |
|---------|--------|------|---------|
| aburiscript | github.com/serjective/aburiscript | ~9MB | Full C/C++ frontend (LLVM IR output) |
| cplusplus | github.com/robertoraggi/cplusplus | ~12MB | C++23 parser library (cxx-frontend) |
| clank | github.com/lethalbit/clank | ~128KB | Lightweight Clang-based C++ frontend |

All cloned with `--depth 1` for reference only. Not part of the MeuOS build.
