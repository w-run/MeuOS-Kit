## 目标增补（大喵，多轮迭代 / 解构型思维 / 多系统参照）
- **多轮查缺补漏无上限**：允许多次调研，以**修订形式追加内容、不删除**；允许拓展调研范围。
- **参考系统拓宽**：Linux 是直接参考，但须同时参照 Windows NT / macOS(XNU) / Android(Binder) / 塞班(Symbian) / ChromeOS(Fuchsia) 等，作为"少走弯路"的参照物。
- **不做缝合怪**：参考是为了取长补短，实现必须**自主研究**；思想可取长补短，实现要自己来。
- **解构型思维**：想象"这部分内核**应该是什么样**"，而非仅罗列"别人怎么设计"。
- 指挥官职责：把控此原则贯穿各子领域；doc-sync 合成 pass 与后续查缺补漏轮次均需施加该透镜。
