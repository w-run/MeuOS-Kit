## 三、关键问题清单

### P0 — 阻塞性问题

1. **mcc `--specs=meuos` segfault**
   - 影响 `meuos-libc` 和 `meow` 的 make check
   - 在编译 `alignas.c`、`compound_lit.c`、`stmt_expr.c`、`vla.c` 等 C11 测试文件时触发
   - 路径：`projects/mcc/` — 需排查 irgen 或 sema 模块

### P1 — 能力不完整

1. **meow pkg-config 无 `.pc` 文件解析** — 仅内置 20 个库的表
2. **libdisasm 仅 x86_64** — 其余 5 架构反汇编未实现
3. **arm 重定位未实现** — 编码器完成，链接器 arm 标记 unsupported
4. **ld.so 默认不构建** — 需显式 `make` 单独构建

### P2 — 文档/代码小偏差

1. **sysroot Python 绑定缺少 `listdir`** — 文档声称有但实际代码没有
2. **sysroot v2 header 64B 注释与实际 72B 不一致**
3. **meow 声称 27 库，实际 25 条/20 唯一**
4. **libc 声称 40+ syscall，实际 61**（超预期，不是问题）

### Phase 6-7 未启动（与文档一致）

- `meuos-utils` (coreutils 替代)
- `meuos-shell` (POSIX sh)
- `meuos-buildtools` (m4/bison/flex/gperf)
