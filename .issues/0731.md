## Bug 记录

### 1. ARM 构建失败：statx.h 缺少 `__arm__` 条件分支（已修复）

**根因**：commit `8e86f2a` 为 18 个 ARM syscall 文件补充了 `__arm__` 条件分支（如 `stat.c` 第 19 行的 `#elif defined(__aarch64__) || defined(__riscv) || defined(__loongarch64) || defined(__arm__)`），但 **`src/internal/arch/i386/statx.h` 第 30 行的内部条件遗漏了 `__arm__`**：

```c
// 原代码（缺少 __arm__）：
#if defined(__aarch64__) || defined(__riscv) || defined(__loongarch64)
#define LINUX_SYS_STATX          332
#endif

// 修复后：
#if defined(__aarch64__) || defined(__riscv) || defined(__loongarch64) || defined(__arm__)
#define LINUX_SYS_STATX          332
#endif
```

**影响文件**：`src/syscall/stat.c`、`src/syscall/fstat.c`、`src/syscall/lstat.c` 在 `__arm__` 分支下都 `#include "../internal/arch/i386/statx.h"`，但头文件不定义 `LINUX_SYS_STATX`，导致编译错误：
```
error: 'LINUX_SYS_STATX' undeclared (first use in this function); did you mean 'LINUX_SYS_STATX_I386'?
```

**修复**：在 `statx.h:30` 加入 `|| defined(__arm__)`。修复后 ARM 构建成功。

### 2. i386 构建失败：mcc 后端功能缺失

**错误**：编译 `src/stdio/fp_fmt.c` 时 mcc 崩溃：
```
src/target/i386/i386_emit.c: dying: i386: Kl op cast not yet supported
```

**影响**：i386 目标完全无法构建。这是 mcc 本身的功能限制，非 meuos-libc 代码问题。

### 3. ARM 代码警告（预存在，非本次引入）

- `src/arch/arm/aeabi.c`：`shift count >= width of type`（udivmod64 函数中的 32 位类型右移 32 位）
- `src/dlfcn.c`：`shift count >= width of type`（rd64 和 ELF64_R_SYM 宏中的移位操作）

这些警告在 32 位 ARM 目标上触发，但不影响链接或运行时行为。

### 4. 工作区维护问题

`projects/sysroot` 是一个断开的符号链接（`../../sysroot/x86_64`），指向工作区外的路径。`make install` 失败（`mkdir: cannot create directory`，因为目标是已存在的符号链接文件而非目录）。移除符号链接并创建目录后可正常安装和测试。
